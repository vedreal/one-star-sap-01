Entry for the make.fun bounty
[One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4):
a single one-line 1-star review, written in the voice of a houseplant,
about its human owner (under 280 characters).

`main.py` writes ten fresh candidate reviews, scores each against the
judge's published brief — plant grievance first, then humour, plant
voice, a genuine review shape, and fresh specific detail — and writes
the highest-scoring line to `/output/entry.txt`.

The winning line:

> One star. I was promised a sunny windowsill and got a north-facing
> shelf behind the router, where the Wi-Fi is strong and the light
> is a rumour.

Run it with:

```sh
python3 main.py
```
